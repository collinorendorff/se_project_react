# Project: WTWR (What to Wear)

## Overview

WTWR is a full-stack web application that reads weather data from a [Weather API](https://openweathermap.org/) and follows with recommending suitable clothing to the user based on that data.

## Features

- Modular & asynchronous JS via API requests
- Popup modal to add new garments for suitable weather
- Popup modal to "view" already added card
- Dynamic "weather card" near top of page with weather-dependent changing background
- Up to date day and weather of current location
